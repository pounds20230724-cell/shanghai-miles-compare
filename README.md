# 上海出发 · 里程票综合对比工具

> 把 **国航凤凰知音 / 东航东方万里行 / 南航明珠** 的里程兑换、税费、现金票价、里程价值、火车票价与时间放进**同一张表**，直接告诉你：这张票该用里程、该坐火车，还是该直接买。

上海是国内三大航竞争最激烈、也是最容易把里程"换亏"的口岸。这个工具把判断过程完整摊开，而不是给一堆需要自己算的兑换表。

## 它回答什么问题

- 这个目的地，**用里程兑经济舱划算吗**？
- 用**里程升公务舱**要多少里程、值不值？
- 面对同一段路，**高铁和飞机到底哪个更便宜**？
- 税费、燃油附加费算进去之后，里程票的真实成本是多少？

## 判定规则（可按自己偏好调整）

```
① 火车又便宜又快                      → 🚄 坐火车
② 火车更便宜，飞机只快 ≤2 小时         → 🚄 坐火车
③ 火车更快但贵 ≤¥150                  → 🚄 坐火车
④ 经济舱里程价值 > 500 元/万           → ✅ 里程换经济
⑤ 公务舱 > 1000 元/万 且 ≥ 经济舱 2 倍  → 💺 里程换公务
⑥ 无铁路 / 火车慢 > 6 小时             → ❌ 买现金票
⑦ 其余                                → ⚖️ 看情况 / ❌ 买现金票
```

**里程价值（元/万）=（现金票 − 税费）÷ 里程 × 10,000**，含义是"每用一万里程能省多少钱"。

> 阈值 500 / 1000 是默认值，也是常旅客圈常用的经验值。你可以按自己的里程余额与估值习惯修改 `src/gen_master.py` 里 `emit()` 的判断条件。

## 数据来源与口径

- **里程**：三家官网公示的标准兑换表单程值。表内三家逐行列明（经济/公务），最低者以绿/紫高亮。国内三家可比；国际以南航在上海无洲际直飞，其距离制换算值为灰色参考显示、不参与"最低"比较。
- **税费**：民航发展基金 50 元 + 燃油附加费（自 2026-10-10 起 ≤800km 为 50 元 / >800km 为 90 元）→ 国内 ¥100 / ¥140。国际为分区域估算中值。
- **现金票**：**一般折扣价**（常规时段提前购票，已排除红眼航班与廉航特价）。国内 = 300 + 0.25×距离；国际 ≤3,000km = 800 + 0.24×距离、>3,000km 分段；公务舱 = 经济舱 ×3（国内）/ ×4（国际）。
- **时间**：飞行+值机 = 飞行时长 + 国内 2h / 国际 3h；火车按线路等级推算（350 高铁 0.50 元/km·均速 210；250 动车 0.40·170；普速硬卧 0.21·90）。
- **火车 vs 飞机**：直接比现金票（火车二等座票价 vs 机票现金价），不拿火车票去比里程票的税费。

⚠️ 距离为约值，现金票价与火车票价为模型估算（误差 ±20%）。**边界航线（600/800/1,200/1,700/1,800/2,000/2,400km）与实际出票前，请以航司里程计算器和 12306 实时结果为准。**

## 本地构建

只需 Python 3，无第三方依赖。

```bash
python3 src/gen_master.py     # 生成 index.html（工具版，单表 12 列）
python3 qa/qa_master.py       # 逐行校验 281 条数据，输出 0 错误
```

`src/gen_full_table.py` 是数据与模型的来源（航点、距离、税费、票价模型、火车模型），同时可生成一份多视图的详细版 `detailed.html`。
`src/gen_master.py` 复用其数据，产出工具版单表页面。

## 自定义

| 想改什么 | 改哪里 |
|---|---|
| 增加/删除航点、修改距离 | `src/gen_full_table.py` 的 `DOMESTIC` / `INTL` 列表 |
| 调整现金票价模型 | `cash_dom()` / `cash_intl()` / `cash_biz()` |
| 调整税费 | `tax_dom()` / `TAX_INTL` |
| 调整火车票价与时长 | `RAIL` 字典、`RAIL_SPEED` / `RAIL_PRICE` |
| 调整判定阈值 | `src/gen_master.py` 的 `emit()` |

改完重跑 `python3 src/gen_master.py` 即可。

```
行数: 281 (应为 281)
分布: {'rail': 27, 'up': 114, 'good': 80, 'bad': 60}
错误数: 0
OK
```
